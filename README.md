# harpaz.pp.ua

האתר האישי של **שלום הרפז** – טכנאי מחשבים בקריית גת, עם כ-20 שנות ניסיון. בנוסף: בניית בוטים, אוטומציות ואתרים לעסקים.

🌐 **האתר:** https://harpaz.pp.ua


## על הפרויקט

אתר שירותים בעמוד בודד (Single Page), בעברית וב-RTL, מותאם לנייד. מטרתו להפוך מבקר ללקוח: להציג את השירותים, לאפשר תמיכה מרחוק, ולהביא פנייה בוואטסאפ, בטלפון או בטופס.

## מבנה העמוד

| סעיף | תוכן |
|---|---|
| פתיחה | כותרת ראשית, כפתורי וואטסאפ וטלפון, רשימת פניות נפוצות שנסגרות |
| שירותים | טכנאות מחשבים · בניית בוטים ואוטומציה · בניית אתרים |
| עליי | רקע מקצועי: טכנאות, שיווק דיגיטלי, בניית אתרים ואבטחת מידע |
| תמיכה מרחוק | הנחיות בשלוש פעולות לחיבור דרך RustDesk |
| צור קשר | טופס פנייה, וואטסאפ, טלפון ומייל |

## תכונות

- עמוד בודד בעברית עם כיווניות RTL מלאה
- עיצוב רספונסיבי (theme-color: `#0B3D41`)
- כפתור וואטסאפ עם הודעה מוכנה מראש, וחיוג ישיר
- **תמיכה מרחוק:** הורדה, הפעלה כמנהל ושליחת המזהה האישי
- **טופס יצירת קשר** (שם, טלפון, הודעה אופציונלית) עם שדה Honeypot נגד ספאם
- הטופס נשלח ל-Cloudflare Worker שמעביר את הפנייה לטלגרם
- קישור "פנייה במייל" במקום חשיפת הכתובת כטקסט

## ארכיטקטורה

```
דפדפן ──► Cloudflare (דומיין) ──► אתר סטטי מ-GitHub Pages
   │
   └─ טופס ──► Cloudflare Worker ──► Telegram
```

| רכיב | תפקיד |
|---|---|
| GitHub / GitHub Pages | אחסון הקוד והגשת האתר |
| Cloudflare | ניהול הדומיין |
| Cloudflare Worker | קבלת פניות מהטופס ושליחתן לטלגרם |
| Telegram | קבלת התראה על כל פנייה חדשה |

## הרצה מקומית

```bash
git clone https://github.com/sh770/harpaz.pp.ua.git
cd harpaz.pp.ua
npx serve .
```

> שליחת הטופס עובדת מול ה-Worker המרוחק בלבד, ולכן בסביבה מקומית ייתכן שהיא תיחסם (CORS).
